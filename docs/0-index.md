# Intermediate R

This guide is for users with some R experience or who have completed the [Introduction to R](https://mdlutoronto.github.io/r-intro/) tutorial. You can work through the guide from start to finish or use it to find help on a specific topic. The topics covered are data manipulation with dplyr, combining data, reshaping data, conditional statements, for loops, and writing functions. 

If you need assistance, fill out the [support request form](https://library.utoronto.ca/contact-us/data-maps).

**Tools:** [R](https://mdlutoronto.github.io/tutorials-search/?tool=R)\
**Data Format:** [Statistics](https://mdlutoronto.github.io/tutorials-search/?dataFormat=Statistics)

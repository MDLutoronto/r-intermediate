# Intermediate R

This guide is for users with some R experience or who have completed the [Introduction to R](https://mdlutoronto.github.io/r-intro/) tutorial. You can work through the guide from start to finish or use it to find help on a specific topic. The topics covered are data manipulation with dplyr, combining data, reshaping data, if statements, for loops, and writing functions. 


**TUTORIAL**: https://mdlutoronto.github.io/r-intermediate/ \
